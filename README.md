# Microsoft Excel Data Analysis & AI Automation Portfolio

This repository contains my personal practice workbooks, MIS dashboards, data models, and VBA automation scripts created while mastering Microsoft Excel from beginner to advanced levels.

---

## 📚 Skills & Concepts I Have Learned

### **1. Excel Foundations & Data Management**
* **Workspace & Navigation:** Efficient workbook navigation, relative vs. absolute cell referencing (`$`), Fill Handle techniques, and productivity keyboard shortcuts.
* **Data Cleaning & Validation:** Building drop-down lists and custom error alerts via Data Validation, removing duplicates, splitting text with Text to Columns, pattern extraction using Flash Fill (`Ctrl + E`), Paste Special, and Go To Special (`Ctrl + G`).
* **Sorting, Filtering & Formatting:** Multi-level custom sorting, AutoFilter, Advanced Filter, and rule- or formula-based Conditional Formatting.

### **2. Core & Corporate Excel Formulas**
* **Lookup & Reference:** `VLOOKUP`, `HLOOKUP`, `LOOKUP`, and `INDEX & MATCH`
* **Conditional Math & Aggregation:** `SUM`, `SUMIF`, `SUMIFS`, `SUMPRODUCT`, `SUBTOTAL`, `AVERAGE`, `AVERAGEIF`, and `AVERAGEIFS`
* **Counting & Statistical:** `COUNT`, `COUNTA`, `COUNTBLANK`, `COUNTIF`, `COUNTIFS`, `FREQUENCY`, `MIN`, and `MAX`
* **Logical & Error Handling:** `IF`, `Nested IF`, `IFS`, `IF` with `AND` / `OR`, and `IFERROR`
* **Text Manipulation:** `LEFT`, `MID`, `RIGHT`, `FIND`, `REPT`, and `SUBSTITUTE`
* **Financial Modeling:** Calculating EMIs and loan amortization schedules using `PMT`, `IPMT`, `PPMT`, `PV`, and `FV`

### **3. Office 365 Dynamic Arrays & Modern Formulas**
* **Modern Lookups:** Two-way and reverse lookups using `XLOOKUP` and `XMATCH`
* **Dynamic Arrays:** Building dynamic reports with `FILTER`, `SORT`, `UNIQUE`, `SEQUENCE`, and `RANDARRAY`
* **Modern Conditional & Text:** `SWITCH`, `TEXTJOIN`, `MAXIFS`, and `MINIFS`
* **Insights & Visualization:** Generating quick insights with Analyze Data and geographic Map Charts

### **4. Pivot Tables & Interactive MIS Dashboards**
* **Pivot Table Reporting:** Custom date/text grouping, Classic and Tabular layouts, Show Values As (`% of Grand Total`, `Running Total`, `Rank`), Calculated Fields & Items, and `GETPIVOTDATA`.
* **Dynamic Ranges & Multi-Sheet Consolidation:** Appending multi-sheet datasets via Power Query and creating dynamic named ranges using `OFFSET`.
* **MIS Dashboard Project:** Designed and built an interactive Call Center KPI Dashboard integrating Pivot Charts, Slicers, Timelines, Form Controls (Spin Buttons), and VBA Macros for auto-refreshing and toggling visuals.

### **5. PowerPivot & Data Modeling with DAX**
* **Relational Data Modeling:** Loading multi-table datasets into the Data Model and establishing One-to-Many (`1:*`) Star Schema relationships between Fact and Dimension tables.
* **DAX Measures & Calculated Columns:** Writing business logic and KPIs using `SUM`, `DISTINCTCOUNT`, `DIVIDE`, `CALCULATE`, `IF`, and `RELATED`.
* **Time Intelligence:** Creating Date/Calendar tables and analyzing trends with `TOTALYTD`, `TOTALQTD`, `TOTALMTD`, `SAMEPERIODLASTYEAR`, and `PREVIOUSMONTH`.

### **6. AI-Assisted Workflows & VBA Automation**
* **Custom Functions with ChatGPT & VBA:** Built custom User-Defined Functions (`ReverseName`, `AddSpace`, `OnlyText`, `OnlyNumbers`, `ExtractAllEmails`) and packaged them as reusable Excel Add-ins (`.xlam`).
* **Process Automation:** Developed VBA scripts to automatically merge multiple Excel files from a folder and send bulk personalized emails via Outlook.
* **Claude AI in Excel:** Practiced automated data cleaning, KPI generation, sales forecasting, and dashboard building directly inside Excel.
